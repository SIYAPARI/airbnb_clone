# airbnb_clone
A full-stack Airbnb clone built using the **MVC (Model-View-Controller)** architecture. This project includes essential features like user authentication, listing creation, updation, image uploads with Cloudinary, and dynamic views.

## 🔧 Tech Stack
- Frontend: EJS, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB with Mongoose
- Authentication: Passport.js (Local Strategy)
- File Storage: Cloudinary

## 🚀 Features
- User Authentication: Register, Login, Logout
- Listing Creation: Add new property listings with images
- Image Uploads: Stored and served from Cloudinary
- Dynamic Views: Rendered using EJS templates
- MVC Architecture: Separation of concerns for scalability and maintainability
- RESTful Routes: For listings, authentication, and user actions



##🔑 Setup Instructions

Follow the steps below to run the project locally:

## 1. Clone the Repository
    git clone https://github.com/SIYAPARI/airbnb_clone.git
    cd airbnb_clone

## 2. Install Dependencies
     npm install

## 3. Create a .env File
    DATABASE_URL=your_mongodb_connection_string
    CLOUDINARY_CLOUD_NAME=your_cloud_name
    CLOUDINARY_API_KEY=your_api_key
    CLOUDINARY_API_SECRET=your_api_secret
    SESSION_SECRET=your_session_secret
    ⚠️ Make sure to replace the placeholders with your actual credentials.

## 4. Start the server 
    node app.js
